## 🎯 How to Access Your Website

### Option 1: GitHub Pages (Recommended)
The website is automatically hosted on GitHub Pages. Access it at:
```
https://github.com/Nayem4954/portfolio
```

GitHub Pages builds the site from your repository and serves it at the GitHub repository URL.

### Option 2: Local Preview
To preview the website locally before publishing:

```bash
cd /path/to/portfolio
# Install Jekyll (if not already installed)
gem install bundler jekyll

# Build and serve locally
jekyll serve

# Visit in browser: http://localhost:4000
```

## 🔄 Updating the Website

To add new publications, presentations, or projects:

1. **Edit the relevant markdown file** in the `_pages/` directory
2. **Add new entries** following the existing format
3. **Commit and push** to GitHub:
   ```bash
   git add _pages/publications.md
   git commit -m "Add new publication"
   git push origin main
   ```
4. **GitHub Pages will automatically rebuild** the website (within 1-2 minutes)
