# About This Website

This repository is HM Nayem's professional portfolio, built as a Jekyll site for GitHub Pages (theme: `jekyll-theme-minimal`).

## Site Structure

| Page | File | Content |
|------|------|---------|
| Home | `index.md` | Introduction, highlights, featured publications |
| Resume | `README.md` | Full resume: education, experience, skills, publications, awards |
| About | `_pages/about.md` | Biography, summary, experience |
| Publications | `PUBLICATIONS.md`, `_pages/publications.md` | 17 published papers and 8 under review, with DOI, PDF and code links |
| Presentations | `PRESENTATIONS.md`, `_pages/presentations.md` | All 23 conference presentations |
| Projects | `PROJECTS.md`, `_pages/projects.md` | Funded projects and research code repositories |
| Skills | `SKILLS.md`, `_pages/skills.md` | Programming, statistical and machine learning skills |
| Publication index | `COMPLETE_PUBLICATIONS.md`, `PAPERS_INDEX.md` | Same list as the Publications page |

Paper PDFs are in `papers/` and `presentations/`.

## Publishing with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Save. The site will be published at `https://nayem-stat.github.io/portfolio/`.

Edit the Markdown files directly on GitHub. Keep `Last Updated` dates current.
